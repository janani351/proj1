# To-Do List App

A responsive task manager built with HTML, CSS and vanilla JavaScript.

## Features
- Add, complete and delete tasks
- Filter all, active and completed tasks
- Edit an existing task
- Persist tasks with browser localStorage
- Clear completed tasks
- Responsive layout and empty-state message

## Run
Open `index.html` in a modern browser. No dependencies or build step required.

## Notes
Data is stored in the current browser's localStorage. Clearing browser site data removes saved tasks.
